# Data Structure Practice

数据结构练习代码，跟着学习一步步实现。

## 内容

### 链表 (List.cpp)
- 带头节点 + 尾指针的单链表
- 头插法 / 尾插法
- 头删 / 尾删
- 按位置查找
- 长度获取

### 迷宫寻路 (maze_solver.cpp)
- DFS 深度优先搜索
- BFS 广度优先搜索（最短路径）
- 可视化打印对比

## 编译运行

使用 Makefile：

```bash
make         # 编译
make run     # 编译并运行
make clean   # 清理
```

## 环境
- 编译器：g++ (MinGW-w64 / MSYS2)
- 标准：C++11
